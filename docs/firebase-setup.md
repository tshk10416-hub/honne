# HONNE の Firebase 設定手順

HONNE を複数のスマホで同時に遊べるようにするための設定です。所要時間は15分ほどで、PCのブラウザで進めるのがおすすめです（スマホでもできます）。費用は無料プラン（Spark）の範囲で収まります。

やることは次の6つです。

1. Firebase プロジェクトを作る
2. 匿名ログインを有効にする
3. Firestore（データベース）を作る
4. セキュリティルールを貼り付ける
5. ウェブアプリを登録して設定値をコピーする
6. 設定値をアプリに入れる

---

## 1. Firebase プロジェクトを作る

1. https://console.firebase.google.com/ を開き、Google アカウントでログインします。
2. 「**プロジェクトを作成**」（または「Firebase プロジェクトを開始」）を押します。
3. プロジェクト名に `honne` と入力して「続行」を押します。
   - 下に表示される「プロジェクトID」（例：`honne-1a2b3`）は後で使うので、メモしておいてください。
4. 「Google アナリティクス」は使わないので **オフ** にして「プロジェクトを作成」を押します。
5. 「新しいプロジェクトの準備ができました」と出たら「続行」を押します。

## 2. 匿名ログインを有効にする

HONNE はユーザー登録なしで遊べるよう、端末ごとに「匿名ログイン」を使います。

1. 左のメニューから「**構築**」→「**Authentication**」を開きます。
2. 「**始める**」を押します。
3. 「**Sign-in method**（ログイン方法）」タブで、一覧から「**匿名**」を選びます。
4. 「**有効にする**」をオンにして「保存」を押します。
5. 続けて「**Settings**（設定）」タブ →「**承認済みドメイン**」を開き、「ドメインの追加」で次を追加します。
   - `tshk10416-hub.github.io`

## 3. Firestore（データベース）を作る

1. 左のメニューから「**構築**」→「**Firestore Database**」を開きます。
2. 「**データベースの作成**」を押します。
3. データベースIDは `(default)` のまま、ロケーションは「**asia-northeast1（東京）**」を選んで「次へ」を押します。
   - ロケーションは後から変更できません。
4. 「**本番環境モードで開始する**」を選んで「作成」を押します。

## 4. セキュリティルールを貼り付ける

ルールは「誰がどのデータを読み書きできるか」の決まりです。これを入れないとアプリは動きません（本番環境モードは最初すべて拒否になっているため）。

1. Firestore Database の画面上部にある「**ルール**」タブを開きます。
2. エディタの中身をすべて消します。
3. リポジトリの [`firestore.rules`](../firestore.rules) を開き、中身を全部コピーして貼り付けます。
   - GitHub で開いた場合は、ファイル右上の「Copy raw file」ボタン（四角が2つ重なったアイコン）で全文をコピーできます。
4. 「**公開**」を押します。

> `firestore.rules` を今後更新したときは、同じ手順で貼り直してください。更新があれば Claude からお知らせします。

## 5. ウェブアプリを登録して設定値をコピーする

1. 左上の歯車アイコン →「**プロジェクトの設定**」を開きます。
2. 「全般」タブの下のほうにある「**マイアプリ**」で、「**</>**」（ウェブ）アイコンを押します。
3. アプリのニックネームに `honne-web` と入力します。
   - 「Firebase Hosting も設定します」には **チェックを入れません**（公開は GitHub Pages で行っているため）。
4. 「**アプリを登録**」を押します。
5. 「Firebase SDK の追加」に、次のようなコードが表示されます。`firebaseConfig` の中の6行が設定値です。

```js
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "honne-1a2b3.firebaseapp.com",
  projectId: "honne-1a2b3",
  storageBucket: "honne-1a2b3.appspot.com",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:abcdef..."
};
```

6. この部分をコピーして「コンソールに進む」を押せば完了です。後から見たいときは、同じ「プロジェクトの設定」→「マイアプリ」→「SDK の設定と構成」→「構成」で再表示できます。

> この設定値は、ウェブページに埋め込んで公開する前提の値で、パスワードではありません。データはステップ4のセキュリティルールで守られます。

## 6. 設定値をアプリに入れる

いちばん簡単なのは、**コピーした `firebaseConfig` をそのままスレッドに貼って送る**方法です。Claude が `public/js/firebase-config.js` に反映してコミットし、公開URLに反映されたらお知らせします。

自分で入れる場合は、次の手順です。

1. GitHub で `public/js/firebase-config.js` を開きます（main ブランチ）。
2. 右上の鉛筆アイコン（Edit this file）を押します。
3. `'YOUR_API_KEY'` などの6つの値を、ステップ5でコピーした値に置き換えます。
4. 「Commit changes...」を押してコミットします。
5. 数分すると GitHub Actions が公開URLに反映します。

## 7. 動作確認

1. スマホ2台で https://tshk10416-hub.github.io/honne/ を開きます。
2. 画面上部に黄色い「ローカルモード」の帯が **出ていない** ことを確認します（出ていたら設定値が入っていません）。
3. それぞれニックネームを登録します。
4. NFCカードがまだなければ、URLの末尾を変えて試せます。
   - Aさんのスマホで `https://tshk10416-hub.github.io/honne/index.html?card=P-0001` を開く → Aさんのカードとして登録
   - Bさんのスマホで `https://tshk10416-hub.github.io/honne/index.html?card=P-0002` を開く → Bさんのカードとして登録
   - Aさんのスマホで `...?card=P-0002` を開く → Bさんに挑戦が届き、受けると対戦開始
5. Firebase コンソールの「Firestore Database」→「データ」タブで、`players` や `duels` にデータが増えていれば成功です。

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 「アクセスが拒否されました」と出る | ステップ4のルールが公開されていません。貼り付けて「公開」を押してください |
| 黄色い「ローカルモード」の帯が出たまま | 設定値が反映されていません。`firebase-config.js` の `apiKey` が `YOUR_` のままになっていないか確認してください。反映直後はブラウザのキャッシュが残ることがあるので、再読み込みしてください |
| 「auth/operation-not-allowed」と出る | ステップ2の匿名ログインが有効になっていません |
| 「auth/unauthorized-domain」と出る | ステップ2の5で `tshk10416-hub.github.io` を承認済みドメインに追加してください |
| 何も表示されず読み込み中のまま | 電波を確認してください。直らなければ、画面のエラー文をスレッドに送ってください |
